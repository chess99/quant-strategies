# 本地日频量化研究平台最终能力审核

## 结论

六轮建设已把本地环境从“只有 A 股日线”推进到可独立承担日频 A 股、ETF、中低频选股和
轮动研究的平台。行情、ETF、历史证券池、估值、交易状态、公告日财务、历史行业、统一接口
和日线撮合均有真实数据验收；小市值与价值质量策略不是目标回放，而是本地自主选股后再与
聚宽完整日志比较。

这不是聚宽全功能复制品。分钟、Tick、集合竞价、资金流、股东/北向、期货和期权明确不在
本期范围；分钟数据也不是当前个人中低频研究的优先项。

## 当前可替代程度

- A 股和主要指数日线、复权、交易日历：可作为本地研究事实源。
- ETF 日线和轮动：可脱离聚宽研究，当前产品覆盖 99.38%。
- 日频横截面、小市值、价值质量策略：可在 B 级限制下完成自主选股、撮合和归因。
- 聚宽常用日频接口：扫描到的八类目标 API 调用中 87.86% 可直接兼容；动态 query DSL
  等复杂形式需要显式迁移，系统不会猜测执行。
- 财务和行业：适合研究及回测，但属于公告日正确、历史修订不严格 vintage 的 B 级数据。

大规模参数实验、因子研究、机器学习、组合优化和完整日线回测可以主要留在本地；聚宽更适合
保留为少量短窗口黄金对照和最终平台兼容检查。

小市值和价值质量聚宽运行的实际初始资金都是 1,000 万元；早期计划文字中的 100 万元不是
平台实际参数。本地正式对照已按 1,000 万元匹配，因此比较口径一致。

## 最后两项审计修正

1. 统一接口补充 `value_metrics`，正式提供 EV、FCF 和 EV/EBIT。现金或有息负债缺失时
   不补零；当前 EV/EBIT 使用最新可见报告累计 EBIT，非 TTM，限制写入溯源。
2. `daily_market_state` 的总体 C 等级改为逐行组件门禁。正式 B 级查询只有在目标行的停牌、
   ST 和涨跌停质量全部达到 B 时才返回；C、未知或缺列会明确拒绝。

另外，ETF 首次复现 v1 缺少名为 `source.py` 的源码快照。旧目录没有被改写，而是新增同
哈希源码附录，闭合可复现性缺口。

机器可读的完整数据覆盖、manifest 哈希、迭代提交、归档审计和限制见
[`final-capability-audit.json`](final-capability-audit.json)。
