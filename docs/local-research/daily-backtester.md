# 日线撮合器

`DailyBacktester` 是面向 A 股与 ETF 中低频研究的可审计日线撮合器。信号应使用前一交易日
或更早数据，订单可在执行日开盘或收盘撮合。

## 已实现能力

- `order_value`、`order_target`、`order_target_value`、`order_target_percent`、
  `order_target_weight` 与组合目标权重调仓；
- 开盘或收盘执行，组合调仓固定先卖后买；
- A 股 100 股整数手、全部清仓时的奇零股处理；
- 股票 T+1；ETF 默认允许日内卖出，可按资产类型配置；
- 股票与 ETF 分别计费；`etf_buy_commission`、`etf_sell_commission` 和
  `etf_minimum_commission` 可独立配置，未配置时兼容沿用股票费率；另支持滑点和
  2000 年以来印花税变更；
- 停牌、ST、涨停、跌停、缺价、现金不足、成交量上限和部分成交；
- 可空停牌/涨跌停标志按“未知”明确拒单，不把 NaN 当成真实阻塞状态；
- 同一证券同一交易日的多笔订单共享成交量额度，卖出失败不释放现金；
- 日、周、月首个或最后一个实际交易日调度；
- 现金分红、送股、拆股、并股和配股的显式公司行为模型；
- 公司行为在输入阶段校验比例与价格，拒绝 NaN、无穷值、负比例和无效倍数；
- 净值、订单、成交、持仓、现金、拒单、费用和公司行为账本；
- 累计/年化收益、最大回撤、Sharpe、波动率、换手、最长水下期、年度收益和现金比例。

正式研究可设置 `minimum_state_quality="B"`。此时状态、ST 或涨跌停任一行低于 B 级，
订单都会以明确原因拒绝，不会使用 C 级规则代理静默成交。

公司行为有两种互斥模式：

1. 原始价格加显式 `corporate_actions` 事件表；适合有完整分红送转配股数据的研究。
2. 连续复权价格且不传公司行为；适合目前免费数据环境。它能保持总收益连续，但股数、名义价格
   和最低佣金不等同于逐事件模拟，报告必须披露这一限制。

## 全市场预检

当前本地自主选股预检归档为
`studies/joinquant-small-cap-golden-comparison/results/2026-07-29__monthly-small-cap__local-preflight-v12/`：

- 2019-01-02 至 2023-06-30，54 次月度调仓；
- 从 6,115 只历史 A 股主表按观察日生命周期展开，前一交易日总市值排序；
- 北交所因免费历史涨跌停为 C 级而显式剔除，不使用代理撮合；
- 每次均得到 10 个目标；实际成交全部通过 A/B 级状态门禁；未来数据违规为 0；
- 初始资金与聚宽实际运行一致为 1,000 万元；本地年化 12.51%，最大回撤 47.56%；
- 源码、引擎、覆盖报告和全部原始账本均记录 SHA-256。

v1 暴露了 C 级涨跌停行仍能成交的问题；v2 开启质量门禁后发现 2023-07 以后免费涨跌停
只有 C 级。二者作为失败审计证据保留，v3 将正式区间截止到 A/B 级事实源末日；v4
绑定可空状态与公司行为数值校验后的当前撮合器；v5 进一步匹配聚宽实际 1,000 万资金，
是当前本地证据。

聚宽 v1 已取得完整 54 个月日志，但候选/持仓重合率为 82.04%/69.79%，日志定位到科创板
市价单缺少保护限价。修正版 v2 同样取得完整 54 个月，候选重合率仍为 82.04%，持仓重合率
提高到 77.87%，证明保护限价修复有效；但平台年化 12.06%、最大回撤 48.02%，与本地仍相差
-18.51/+14.25 个百分点。

后续核验确认 `missing_open` 是真实停牌，聚宽也保留相同残留仓位；不能用补价方式消除。
真正的撮合差异是本地把同权重买单按代码排序，而聚宽按候选优先级下单。修复后，复用 v2
已归档目标的 `local-jq-target-replay-v2` 无需新增平台运行，持仓和下单证券重合率达到
98.50% 和 98.60%，本地年化 13.03%、最大回撤 47.34%，与聚宽只差 +0.97 和 -0.68 个
百分点，全部通过既定阈值。

最终 v12 修复了估值日历和状态有效期语义，仍使用本地点时总市值自主选股。它复用聚宽
`fd4f04ed4711b333961fec6244c16e84` 的既有完整日志生成 autonomous-v4 对照，没有新增平台运行
或额度消耗。候选、实际持仓和下单证券重合率分别为 100.00%、98.70% 和 98.59%；本地年化
12.51%、最大回撤 47.56%，与聚宽只差 +0.45 和 -0.46 个百分点。最终结果不再依赖聚宽目标
回放，完整策略直跑也达到严格门槛。
