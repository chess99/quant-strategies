# 比尔·米勒风格 A 股量化策略

## 投资假设

策略尝试把“市场预期与企业长期经济价值之间的差距”转为可回测的横截面模型。当前基线同时覆盖普通企业、金融企业和亏损成长企业，结合估值、质量、资本效率、会计质量和逆向信号。

## 文件

- `baseline.py`：当前可直接复制到聚宽的自包含基线。
- `variants/`：同一投资逻辑的小变体。
- `tests/`：纯函数、组合构建和聚宽兼容性测试。
- `backtests/`：不可变回测归档。

## 当前基线

- 月度调仓
- 目标持股 20 只
- 新进排名前 15，持有缓冲至前 40
- 最低上市 500 天
- 20 日平均成交额不低于 2000 万元
- 单股上限 8%，行业上限 25%
- 金融模型上限 30%，亏损成长模型上限 20%

## 变体

| 变体 | 假设差异 | 状态 |
|---|---|---|
| baseline | 三模型价值与预期差基线 | baseline |
| allocator-redistribution | 约束削减后的权重重新分配，消除被动现金 | planned |
| catalyst-filter | 增加基本面改善或价格确认，减少价值陷阱 | planned |
| portfolio-risk-overlay | 增加组合波动和市场风险覆盖层 | planned |

## 已知限制

- 大部分财富增长集中在 2009 和 2015 两年。
- 2015 年底至 2025 年底策略仍为负收益。
- 当前权重约束削减后不会重新分配，导致平均约 16% 被动现金。
- 估值指标相关性较高，便宜因子可能被重复计权。
- 缺少对“估值便宜但没有催化剂”的明确识别。
