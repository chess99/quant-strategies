# 本地日频研究环境建设路线

## 目标与边界

目标是在个人可维护的范围内，让 A 股、ETF 和主要指数的日频、中低频策略研究
大多数时候不依赖聚宽。聚宽保留为少量黄金对照、平台兼容性检查和最终交付环境。

首期不建设分钟、Tick、集合竞价、期货和期权能力，也不承诺模拟涨停排队等逐笔行为。

## 质量底线

- 所有查询都必须有观察日期，不使用当前证券、行业或财务状态倒推历史。
- 数据按 `A/B/C` 分级；策略可以声明最低等级，数据不足时拒绝运行。
- 原始下载不可变保存；规范化数据使用 Parquet，小型字典、清单和报告使用 JSON/CSV。
- 每个数据集记录来源、抓取时间、覆盖区间、行数、文件 SHA-256 和已知限制。
- 每次数据更新执行字段、区间、重复、异常收益和点时可见性检查。
- 免费数据无法恢复严格历史修订时必须标为 B 或 C，不以代理数据冒充 A 级。

## 外部目录

默认数据根目录：`D:/code/_open-source/_data/quant-research/`。

```text
quant-research/
  raw/{provider}/{dataset}/
  normalized/{dataset}/{partition-columns}/
  manifests/{dataset}.json
  snapshots/{dataset}/
  quarantine/
```

可通过环境变量 `QUANT_RESEARCH_DATA_DIR` 覆盖。仓库只保存代码、契约、测试和
体积可控的验收报告，不提交外部数据、密钥或 Cookie。
