# 科创 50 ETF 单标的择时横向研究

## 研究问题与落点

本研究重新检查科创 50 ETF `588000` 上的简单 MACD 结论，并比较几类彼此不同的
单标的择时假设。当前落点是 `studies/`，不是策略簇：MACD 趋势、均线趋势、突破、
均值回归和 Elder 三重滤网的核心投资假设不同，不应为了共享一个标的而放进同一策略族。
只有某一种机制通过本协议后，才为该机制单独建立策略簇。

旧研究笔记为
`D:/code/Notes/投资调研/回测研究/20260508-Elder三重滤网ETF横向对比.md`。
旧笔记记录科创 50 上简单 MACD 年化约 `25.6%`，但没有保存该 MACD 实验的精确源码、
逐日净值和交易记录。本次只能把它视为待复核线索，不能视为可复现基线。

## 事前固定口径

- 研究标的：华夏上证科创板 50 ETF `SH588000`，不在结果生成后替换标的。
- 数据：仓库本地 ETF 日线 B 级事实源，使用连续复权 OHLCV；数据末日由 manifest 固定。
- 预热：先使用 252 个交易日，只计算指标、不计入业绩；所有模型从下一交易日开始用
  同一个起点评价。
- 信号：只使用观察日收盘及以前数据。
- 执行：默认下一交易日开盘；目标风险仓位为 99%，100 份整数手。
- 基础成本：ETF 买卖佣金均为万三、最低 5 元、单边 2bp 滑点，不征股票印花税。
- 压力成本：佣金不变，单边滑点提高到 10bp。
- 初始资金：100 万元。
- 基准：相同评价起点、相同基础成本下买入并持有 99% 仓位。
- 无风险利率：绩效 Sharpe 使用 0；现金不计利息。
- 年化交易日：252 日。

ETF 免费日线没有逐日权威停牌、涨跌停和盘口状态。本研究按日线存在即为可交易的 C 级
代理状态撮合，并保留 10% 日成交量上限。`588000` 流动性很高、研究资金仅 100 万元，
成交量上限预计不构成约束；但该假设仍须在结果报告中披露，不能把本地结果直接称为
聚宽或实盘结果。

## 第一阶段固定模型

| 标识 | 机制 | 固定规则 |
|---|---|---|
| `buy-hold` | Beta 基准 | 评价首日下一可用开盘持有 99% |
| `macd-cross-12-26-9` | MACD 金叉/死叉 | `DIFF > DEA` 持有，否则现金 |
| `macd-zero-9-24` | MACD 主线零轴 | `EMA(9) > EMA(24)` 持有，否则现金 |
| `sma-200` | 长期趋势 | 收盘价高于 200 日简单均线时持有 |
| `tsmom-252-monthly` | 时间序列动量 | 月末观察，12 个月收益为正时持有 |
| `donchian-120-40` | 突破趋势 | 突破此前 120 日最高价入场，跌破此前 40 日最低价退出 |
| `bollinger-20-2` | 均值回归 | 跌破 20 日均值减 2 倍标准差入场，回到均值退出 |
| `elder-risk-sized` | 原 Elder 框架 | 周线趋势 + 日线回调，2ATR 止损，2% 风险预算、20% 仓位上限 |
| `elder-full-exposure` | Elder 信号消融 | 与上一模型同信号，但每次入场使用 99% 仓位 |

`macd-cross-12-26-9` 才是日常所说的金叉/死叉；`macd-zero-9-24` 复现仓库中已独立验证过的
聚宽“MACD 大盘择时”主线穿零逻辑。两者必须分开报告，不能都简称为“MACD”。

Elder 使用完整周结束后的周线 EMA(26) 与 MACD 柱，不允许周一至周四读取尚未结束的
本周数据；周五收盘信号最早在下一交易日开盘执行。日线随机指标、Force Index 和 ATR
同样只使用观察日及以前数据。

## 稳健性与旧结论复核

1. 完整输出三个预先固定阶段：评价起点至 2022-12-31、2023-01-01 至 2024-12-31、
   2025-01-01 至数据末日。
2. 所有主动模型运行基础成本与 10bp 滑点压力，不只给零成本毛收益。
3. 对 `macd-cross-12-26-9` 运行 `fast={8,12,16}`、`slow={21,26,34}`、
   `signal={7,9,12}` 的全部 27 组邻域，不根据结果删组合或替换中心参数。
4. 对标准 MACD 运行下一开盘、下一收盘、再延迟一个交易日开盘三种时点。
5. 单独报告旧笔记区间 2022-01-04 至 2026-04-30，但不把该区间称为样本外。
6. 使用 20 日移动区块、固定随机种子和 2,000 次重采样，估计每个主动模型相对
   买入持有的年化平均日收益差置信区间；单侧 p 值使用 Holm 法校正多模型比较。

## 事前成功标准

本轮只把模型标为“可进入策略簇候选”，不直接标为可交易。候选必须同时满足：

1. 全期年化收益与 Sharpe 都高于买入持有，最大回撤至少降低 10 个百分点；
2. 三个固定阶段均为正收益；
3. 10bp 单边滑点压力下仍为正年化；
4. Holm 校正后的单侧 `p < 0.10`；
5. 若候选是标准 MACD，27 组参数邻域至少 70% 为正年化，且至少 70% 的年化收益
   高于买入持有。

任何一项失败都不晋升。本样本只有约五年有效评价期，且 2022—2026 已被旧实验观察过；
即使全部通过，也只能说明历史机制值得冻结后前瞻跟踪，不能证明未来 Alpha。

## 首轮结果

首轮不可变归档见
[`results/2026-09-01__canonical-mechanism-comparison__local-etf-2021-2026-v1/`](results/2026-09-01__canonical-mechanism-comparison__local-etf-2021-2026-v1/)。

- 统一评价期为 2021-11-29 至 2026-07-24；买入持有年化 5.10%、最大回撤 55.45%。
- 标准 MACD 金叉/死叉年化 25.11%、最大回撤 27.36%、Sharpe 1.01；旧笔记区间
  复算年化 23.93%，与旧记录的 25.6% 同方向。
- 27 组 MACD 参数邻域全部正年化、全部跑赢买入持有；下一收盘和再延迟一日开盘仍分别
  年化 17.72% 和 18.37%。
- 标准 MACD 六项门槛通过五项，但区块自助法原始单侧 `p=0.0340`，八模型 Holm 校正后
  `p=0.2719`，未通过事前统计门槛。因此本轮没有模型晋升为策略簇候选。
- Elder 风险定仓版年化 1.97%、最大回撤 5.64%；低回撤主要来自平均约 4.4% 的实际资金
  暴露，而不是与满仓基准同风险的显著 Alpha。Elder 满仓信号年化 8.62%、最大回撤 25.82%。

结论是“MACD 是值得冻结跟踪的最强线索”，不是“已经得到可交易策略”。后续不在该历史
样本上继续优化参数；需要先积累前瞻数据，或提出新的经济机制后另行预注册实验。
