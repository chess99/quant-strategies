# 五福 7.5 ETF 轮动拆解

## 研究问题

本策略族不把五福 7.5 的公开高收益视为已验证事实，而是检验其结构是否具有可迁移的历史
边际：短周期趋势、R² 趋势质量、普通健康过滤、持仓缓冲、A 股强弱切换、B 型主线、主线
延续与日内买入确认分别贡献了什么。

原始只读源码位于 `joinquant_archive/sources/ETF轮动策略/五福7.5.py`，冻结 SHA-256 为
`91735fb99bd9afb80c0a4a50e2c6ec3753676fa85b119b6f19a659e50c55178f`。公开回测 JSON
SHA-256 为 `cc9cd8fcdc5795235f4a46fb8d69d5264fb19b9fb33418fe11d912a89ad44bb5`。
本策略族不改写这两个只读来源。

## 因果执行基线

五福原版在 13:10 使用当日实时价格生成信号，并在 13:10—14:55 买入。本地数据只有日线，
因此批量实验冻结为：观察日收盘后生成目标，下一交易日开盘执行。它用于比较模块边际，不冒充
五福公开分钟回测的精确复现。精确日内模块另用聚宽分钟数据校准，并与“14:55 强制买入”配对。

`baseline.py` 是可直接上传聚宽的因果日频基线；`research.py` 是本地批量实验引擎。两者共享
同一组冻结参数，但本地研究还承担容量、归因、滚动和过拟合诊断。

## 事前模型阶梯

| 阶段 | 新增规则 | 要回答的问题 |
|---|---|---|
| A0 | 25 日加权对数斜率为正，按年化斜率排名 | 裸短期相对动量是否有效 |
| A1 | 以年化斜率×R²排名，并要求 R²>0.4 | 趋势质量是否带来增量 |
| A2 | score≤5、MA10、普通量比、三日急跌、震荡量价背离 | 普通过滤是否有效 |
| A3 | 老持仓得分不低于冠军的90%则保留 | 缓冲能否降低换手 |
| A4 | 四指数3/4低于MA10时只用全球/商品池 | 强弱切换是否有效 |
| A5 | 加入冻结阈值的 B 型主线准入 | 超强趋势例外是否有效 |
| A6 | B 型持仓 score>20 时按 R²/Laplace 延续 | 延续是否避免过早退出 |
| A7 | 30分钟斜率/R²分时确认，14:55强制买入 | 日内规则是否改善成交 |

A0—A6 在 Top1 和 Top3 下均运行；另做最终模型逐模块 leave-one-out 和可识别模块全因子配对，
避免只依赖单条“剥洋葱”路径。

## 事前稳健性矩阵

- 候选池：原固定池、原固定池+历史生命周期动态池、纯历史生命周期全ETF池、只使用2023年末
  前已上市ETF；所有证券均按观察日上市/退市状态过滤；
- 参数邻域：lookback 20/23/25/30，R² 0.3/0.4/0.5，score 上限3/5/8，buffer
  0.85/0.90/0.95，TopK 1/3，共216组；
- B 型单参数扰动：score区间、R²、量比、连续性和增长倍数分别上下扰动，不从结果中挑新基线；
- 成本：单边总成本2/5/10/20/30bp；
- 资金：20万、100万、500万、1000万、5000万元；每笔参与率0.5%/1%/5%，未成交部分保留；
- 集中度：ETF贡献Top1/Top3/Top5、删除后重新排名、按上市年份和主题贡献；
- 时间：逐年、2015—2018/2019—2022/2023—2026、滚动3年、因果牛熊震荡；
- 样本外：2019年起 expanding-window，每年只用此前历史在冻结候选中选择，下一年整年执行；
- 多重试验：216组参数用于 CSCV/PBO 与 Deflated Sharpe，明确记录所有直接和派生试验数；
- 平台：聚宽 Research/官方环境校准日频目标；A7 只以分钟数据结果下结论。

## 事前判断标准

1. 普通模块称为“稳定正贡献”须满足：Top1/Top3配对平均 ΔSharpe≥0.05，且三个分段中至少
   两段 ΔSharpe>0；
2. 缓冲模块称为“有执行价值”须降低换手至少20%，且 Sharpe 不恶化超过0.05；
3. A6 须全样本年化为正、Sharpe≥0.5、最大回撤≤40%、最差滚动3年收益为正；
4. 20bp成本与1000万元/0.5% ADV下仍须年化为正，容量场景平均目标风险暴露不低于70%；
5. 删除Top1/Top3贡献ETF后仍为正年化，且保留至少冻结A6年化的70%；
6. 参数邻域至少70%为正年化，中位Sharpe≥0.5；冻结参数不得仅是孤立尖峰；
7. expanding-window OOS须为正年化且最差年度不低于-20%；PBO<25%、冻结候选DSR>95%；
8. A7必须在不改变目标ETF的前提下，相对无确认/14:55强制基准改善成交后Sharpe，且至少两个
   分段为正边际；没有分钟数据时不得把日线开/收盘敏感性称为A7验证。

未达到标准的模块仍完整归档，不根据本轮结果修改阈值或候选池。

## 数据限制

- ETF日线来自本地多源B级数据，覆盖1,781只候选和125只历史终止ETF，使用连续复权价；
- 原版动态池用当前基金名称的字符串启发式去重，本地可复现该算法，但名称本身不是严格历史点时；
- 跟踪标的历史点时分类只在聚宽 `finance.FUND_INVEST_TARGET` 校准路径可用；
- 四指数强弱使用独立指数日线，观察日收盘后才可用于下一交易日；
- 全部历史仍是研究者可见样本，walk-forward与PBO只能降低、不能消除数据挖掘风险。
