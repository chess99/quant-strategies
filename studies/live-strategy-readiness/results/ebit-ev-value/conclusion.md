# EBIT/EV 单因子：版本校准结论

## 事实

- 帖子在 2020-01-03 发布后从未修改，正文、源码与公开回测均固定为月度、50 只、持续满仓和 EBIT/EV 降序，但缺少发布前不可变源码哈希。
- 本地没有深证成指历史成员，且公开免费财务字段不等同于聚宽因子库；事前协议因此固定用历史全 A 股及公告日可见的 `EBIT / (市值 + 有息负债 - 现金)` 代理，并要求先通过 2009—2019 公开窗口校准。
- 本地年化 12.38%、最大回撤 44.85%、Sharpe 0.75；公开结果为 22.55%、39.63%、0.71。回撤和 Sharpe 通过容差，年化差 10.16 个百分点，超过 5 个百分点门槛。
- 132 个月中只有 87.88% 能形成完整 50 只有效候选，低于 90% 门槛；实际月初持仓中位数为 41 只。
- 所有财务选择均满足 `notice_date <= observation_date`，未来公告行数为 0。未通过不是因使用未来数据，而是原证券池/因子库口径无法由当前生产数据稳定复现。
- 失败订单按协议逐日重试，公开窗口共记录 104036 次零成交拒单；这进一步说明缺失候选和不可交易状态不能被静默当成满仓。
- 程序没有计算 2020-01-06 至 2026-07-24 的策略表现，也没有用发布后数据选择 universe、财务字段或持仓数。

## 推断

严格点时的 EBIT/EV 代理在公开窗口仍有正收益和可接受 Sharpe，但它不是公开策略的可信复刻。年化差异可能同时来自深证成指成员缺失、聚宽 financial_liability/financial_assets 定义、免费源 EBIT 代理和真实拒单；无法把其中任一项事后改到最接近公开曲线后再称为发布后 OOS。

## 决定

候选降为 **R0** 并停止。只有取得可审计的深证成指历史成员和聚宽因子字段定义，才能按原版本重新校准；若改用全 A 股和公开财务字段，应作为新策略先冻结开发/评估窗口，不能复用本候选的 2020 年后窗口作天然 OOS。
