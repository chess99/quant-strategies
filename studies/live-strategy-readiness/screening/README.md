# 阶段 0：Archive 全量盘点

本目录是 `protocol.json` 预注册后的第一批机器筛选结果，基于 2026-07-27 的
JoinQuant Archive 快照，并以 2026-08-25 作为发布后窗口的观察截止日。

## 本轮结果

- 593 份来源全部匹配到 UTF-8 源码快照，其中 503 份有公开回测；
- 基于源码指纹、共同原帖、核心函数和 token 相似度聚为 445 个谱系；
- 415 份来源拥有“回测截止日接近发帖日、发帖后超过一年”的可检查窗口；
- 现有归档没有任何源码快照带有可证明早于该窗口的不可变时间戳，因此严格天然 OOS 为 0；
- `candidate-shortlist.csv` 从不同谱系各取一份，共 50 份，预注册的三个 P0 候选均已进入队列。

这里的 415 份只表示存在发布后回放窗口，不表示已经拥有可信的前瞻证据。它们的
`oos_integrity_grade` 均为 C，必须先核验源码版本；无法核验时，发布后结果只能作为降级证据。

## 四张结果表

- `archive-universe.csv`：来源、帖子、公开回测、源码复杂度、API 依赖和静态风险标记；
- `strategy-lineage.csv`：谱系、最近相似来源、源码/核心函数相似度、共同原帖和共同作者；
- `natural-oos.csv`：回测截止日至发帖的间隔、可用发布后天数和版本可信度；
- `candidate-shortlist.csv`：去重后的 50 份候选、分项得分、研究队列和下一步动作。

短名单分数以发布后证据价值、历史长度、因果可修复性、生产数据与执行可行性、简单度和
谱系独立性为主体。Sharpe 与回撤只占少量同分排序权重；CAGR 不进入分数。三个 P0 是预注册
优先级，因此带固定优先奖励，不是根据本轮结果事后挑选。

谱系是机器初筛，不是人工确认的投资逻辑族。公共向导模板、长段共同脚手架和同源改版会形成
大谱系；进入单策略研究前仍须人工确认，不应根据机器聚类直接覆盖或删除任何来源。
