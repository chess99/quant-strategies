# 变体

本轮参数和模块开关全部由 `research.py` 按冻结协议生成，不把样本内冠军写成平台变体。
只有经过事前成功标准和平台校准的结构才会在未来迭代中新增独立 `.py` 变体。

2026-08-21 的可交易化 v3 已完成 136 次直接回测，但只通过 16 项事前门槛中的 9 项，不替换
`baseline.py`。用户明确将 1000 万容量场景降为研究信息后，新增
`tradability_v3_fixed_pool.py` 作为可直接上传聚宽的个人规模研究变体；它仍未通过其余六项适用性
门槛，不代表已验证或建议实盘采用。

| 文件 | 状态 | 相对基线的主要差异 |
|---|---|---|
| `tradability_v3_fixed_pool.py` | 平台试跑候选 | Top3、直接弱市换池、Top5名次缓冲、五交易日调仓、10bp成本、无A7/主线例外 |

该变体使用冻结固定池，不能冒充本地 `original_like` 代理池的逐日复现。聚宽运行结果应另建不可变
回测归档，不覆盖本地 v3 归档。
