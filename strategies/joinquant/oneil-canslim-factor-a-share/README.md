# 欧奈尔 CANSLIM 券商月频因子 A 股策略

## 为什么单独建族

原有 `oneil-canslim-a-share` 是周频建观察池、日频等待放量突破、跟进日控制市场状态、
7.5%止损和金字塔加仓的交易系统。公开券商 CANSLIM 研究则是月初横截面选股、等权
持有和月度再平衡。二者的数据模型、执行方式和持有逻辑根本不同，不能用前者几乎
空仓的结果否定后者。

## 当前基线

`baseline.py` 是可复制到聚宽的华创2019可得数据版：

- 最新单季 EPS 同比不低于18%，营收同比不低于25%；
- 最近五个可见年度归母净利润均为正且逐年增长，四年 CAGR 不低于15%；
- 位于52周高点5%以内，一年 RPS 横截面不低于80；
- 历史沪深300与中证500成分股，月初观察前一交易日、当日开盘调仓；
- 等权、单股不超过5%，单边成本0.13%，另加每股0.002元滑点；
- 缺失的机构持有数和北向持股保持缺失，不用价量代理冒充。

该基线用于忠实暴露严格版的缺陷，不代表当前推荐。研究优先级最高的是
`huachuang-2-risk-scaled`：华创2.0轻量选股不变，弱市缩至50%仓位。

## 结论边界

- 2024—2025 行情已经被用于本轮诊断，结果不是干净样本外验证。
- 本地财务缓存约1310只股票，只覆盖区间内历史沪深300与中证500成员，不是全A。
- 报告按公告日可见，但旧报告可能使用后来修订版本；行业是当前分类。
- 没有点时基金持仓、北向持股、业绩预告/快报和分析师一致预期。
- 月频模型没有欧奈尔7%—8%止损，华创2.0轻量版的 -52.31% 回撤是真实警告。
- 任何版本在补齐数据、全A验证、成本压力和冻结后的样本外检验前都只是研究假设。
