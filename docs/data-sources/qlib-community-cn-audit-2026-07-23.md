# Qlib 社区中国日线数据验收记录（2026-07-23）

## 结论

本数据包**有条件通过研究用途验收**。

它适合用于 KTV + MACD 这类只依赖日线 OHLC、成交额和历史指数成分的本地粗回测，也足以覆盖 2019—2025。它不应未经清洗直接作为正式交易事实源，也不能单独支撑需要财务、估值、ST 状态或精确涨跌停信息的策略。

使用前至少执行以下约束：

1. 股票池使用按日期变化的 `csi300.txt` 与 `csi500.txt`，不得用当前成分倒推历史。
2. 排除 `SZ302132`；其 2025-02-24 复权因子异常，制造了约 488.51% 的虚假调整价涨幅。
3. 信号价格使用 Qlib 调整价 `close`；原始价格按 `close / factor` 恢复。
4. `amount` 沿用 Tushare 的千元单位；映射到聚宽 `money` 时乘以 1000。
5. 北交所暂不纳入当前策略。2025-10 前后的代码迁移会把同一证券拆成旧代码和 `920xxx` 新代码，需要另做身份映射。
6. 对每次数据更新重新运行异常收益、字段完整性和指数成分区间检查。

### 字段

全部 6,121 个证券都具有相同的 10 个日线字段：

```text
open high low close volume factor amount vwap change adjclose
```

每个二进制文件的起始日历索引、长度和对应证券在 `all.txt` 中的起止日期一致；没有发现文件缺失、长度错位、负价格、负成交量或 OHLC 高低关系错误。

字段口径：

- `open/high/low/close`：Qlib 归一化后的调整价；每只证券首个有效收盘价通常归一到 1。
- `factor`：`调整价 / 原始价`，所以 `close / factor` 可恢复原始收盘价。
- `volume`：随复权处理后的成交量，适合做相对量能，不应直接当作原始股数。
- `amount`：未复权成交额，来源沿用 Tushare 千元口径。
- `adjclose`：社区数据源合并过程中的调整收盘价，不是当前策略必须字段。

## 历史指数成分

数据包包含：

```text
csi300.txt
csi500.txt
csi800.txt
csi1000.txt
csiall.txt
```

文件记录证券及其有效起止区间，能按观察日恢复历史成分，避免当前成分股倒推历史的生存者偏差。抽查 2019—2026，沪深300每天为 300 只；中证500通常为 500 只，少数边界日为 501 只。区间是闭区间，组合两个指数时应先按证券代码去重。

当前 KTV 基线应直接合并 `csi300` 与 `csi500` 的观察日成员，不必依赖 `csi800.txt`，这样与聚宽源码的股票池定义一致。

## 已确认的数据异常

### `SZ302132`

该证券在 `csi500.txt` 中从 2023-12-29 开始出现，但自身行情在 `all.txt` 中到 2025-02-17 才开始，历史成分区间与行情区间矛盾。

2025-02-21 至 2025-02-24：

| 项目 | 2025-02-21 | 2025-02-24 |
|---|---:|---:|
| 调整收盘价 | 0.967505 | 5.693869 |
| factor | 0.014704 | 0.087868 |
| 恢复后的原始收盘价 | 65.80 | 64.80 |

原始价格实际下跌约 1.52%，但错误的复权因子使调整价上涨约 488.51%。在 2019—2025 沪深300与中证500历史有效成员约 136 万个相邻交易日观测中，这是唯一一个绝对调整价涨跌幅超过 21% 的事件，明显偏离 A 股大中盘股票的正常日涨跌范围。

处理方式：当前研究直接排除 `SZ302132`，并在数据入口增加“相邻有效交易日绝对调整价收益超过 30% 时拒绝该证券”的健康检查。不要只删除异常日后继续计算指标，因为 160 日窗口内的 KTV、MACD 和均线都会受到污染。

### 指数区间与行情区间

历史上还存在少量指数成分结束日晚于证券行情结束日的记录，多数与退市、换股或区间端点有关。对 2019—2025 的当前股票池，除 `SZ302132` 外，缺失行情会自然阻止产生完整的 160 日信号，但回测器仍应要求：

```text
观察日位于指数有效区间
且观察日前至少有策略要求的有效历史行数
且下单日存在可成交行情
```

## Qlib API 兼容性

使用 `pyqlib 0.9.7` 已验证：

- `qlib.init()` 可正常初始化本地目录。
- `D.calendar()` 可读取 2019—2025 的 1,699 个交易日。
- `D.list_instruments()` 可按观察日读取 `csi300`、`csi500` 和 `all`。
- `D.features()` 可读取 OHLCV、`factor`、`amount`，并可直接计算 `$close/$factor`。

Windows 下从标准输入运行脚本时，应设置：

```python
qlib.init(
    provider_uri=DATA_DIR,
    region="cn",
    kernels=4,
    joblib_backend="threading",
)
```

使用默认 `multiprocessing` 执行从标准输入传入的脚本，可能因 Windows `spawn` 机制重复启动；正式 `.py` 文件也应使用 `if __name__ == "__main__":` 保护入口。

## 当前 KTV 基线的本地性能实测

测试口径：

- 股票池：2019—2025 曾进入沪深300或中证500的历史证券，并排除 `SZ302132`
- 证券数：1,309
- 读取区间：2018-05-01 至 2025-12-31，给 2019 年信号预留 160 日历史
- 数据行：2,244,682
- 有效收盘价：2,233,176
- 指标：直接调用当前 `baseline.py` 的 MA20、MA60、MA120、透明 KTV 和 MACD 实现

本机单次结果：

| 阶段 | 耗时 |
|---|---:|
| Qlib 读取 `close` 与 `amount` | 6.229 秒 |
| 计算全部基线指标 | 8.221 秒 |
| 合计 | 14.450 秒 |

这证明“本地一次预计算并复用指标”在当前机器上是可行的。14.45 秒只包括数据读取与指标计算，不包括撮合、持仓和绩效统计；完整日线回测仍应是秒到分钟级，而不是聚宽逐周重复拉取 160 日行情所需的约两小时。

## 与聚宽基线的差异

Qlib 包本身没有以下聚宽状态：

- 每日证券名称与 ST 标记
- 精确的历史涨停价、跌停价
- 聚宽 `current_data` 的停牌和退市名称状态
- 财务、估值、行业等基本面字段

对 KTV + MACD 粗回测可采用以下替代：

- 停牌：OHLC 或成交量缺失时不交易。
- 流动性：`money = amount * 1000`。
- 上市日期：使用 `all.txt` 起始日。
- 股票池：使用历史 `csi300` + `csi500` 成分，指数本身已过滤大量 ST 和低质量证券。
- 涨跌停：第一版以“当日有成交且开盘价有效”为近似；后续若要和聚宽逐笔对齐，再补历史涨跌停与 ST 数据。

因此，本数据适合回答“这套双指标共振有没有统计价值”，但第一版本地结果不应宣称与聚宽撮合结果逐笔一致。

| 策略 | 结论 |
|---|---|
| KTV + MACD 日线策略 | 可用，需执行上述清洗和口径映射 |
