# 全市场价值质量黄金对照

本研究用于验收第 6 轮的完整链路：6,115 只历史 A 股证券主表、公告日约束财务、
观察日估值、申万历史一级行业、A/B 级交易状态和统一日线撮合器。

策略在每月首个交易日开盘调仓，使用前一交易日作为观察日。先在行业内综合低
PE/PB/PS 与高 ROE/ROA/毛利率/净利率、低资产负债率，再限制每个申万一级行业最多
3 只，等权持有 20 只。北交所历史涨跌停在免费数据中为 C，因此黄金区间显式排除。

验收分两步：

1. `run_local.py` 完成 2019-01-02 至 2023-06-30 的全量本地预检并归档。当前最终证据是
   `results/2026-07-28__monthly-value-quality__local-preflight-v5/`，初始资金与聚宽一致为
   1,000 万元；它绑定修复数值代码与上证指数重号污染后的申万行业 manifest。v1-v4
   作为失败或被替代实验保持不可变。
2. `joinquant_strategy.py` 在聚宽只运行一次，导出日志与统计后由导入器比较逐月目标、
   持仓、订单、年化收益和最大回撤。

本地预检通过不等于黄金对照通过。只有目标和持仓平均重合率至少 80%，且年化和最大
回撤差分别不超过 3 个百分点，才能完成第 6 轮。

首次聚宽运行 `924847c2fb96995f318cce5321594568` 的源码与当时准备源码 SHA-256 完全
一致，平台年化 17.69%、最大回撤 26.21%，本地分别为 11.61% 和 31.03%。免费日志接口
硬截断于 1,000 行，只覆盖 34/54 个候选日和 33/54 个持仓日，失败证据已归档为
`2026-07-28__monthly-value-quality__joinquant-golden-v1`。在双方均有日志的月份中，目标和
持仓平均重合率约为 62%，说明除了日志截断，还存在财务、估值或行业口径差异。

修正版聚宽运行 `c29fcd867c0701ef9254567a93475cef` 已归档为
`2026-07-28__monthly-value-quality__joinquant-golden-v2`。紧凑日志在免费接口内取得完整
54/54 个候选、订单和持仓月份，证明无需花 3 积分导出。平台实际源码与准备源码一致。

并非日志截断假象，主要问题确定为聚宽与东方财富在估值、财务报告期或历史行业上的口径差异。
