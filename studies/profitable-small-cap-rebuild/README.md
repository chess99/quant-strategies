# 盈利质量小市值重建研究

本研究从聚宽帖子 `45510` 的10只低价小市值策略出发，完成以下顺序固定的实验：

1. 复现原帖可由日线表达的核心规则；
2. 修正点时财务、股票成本、流动性、行业集中和成交约束；
3. 在不读取发布后结果的前提下定义15/20/30只、风险覆盖和成本/容量邻域；
4. 用2023-12-01以后区间检查发布后表现；
5. 选出120日趋势、风险期50%仓位、20只股票的偏实盘候选。

`results/2026-08-02__curated-summary__local-qlib-2014-2026-v1/` 保存三阶段完整比较表和
原帖核心的净值、成交与选择明细。最终候选的完整账本在策略族不可变回测归档中。

研究过程中保留的失败事实：首次统计未处理空成交分段；第二次运行把 Qlib 千元成交额误作
人民币元，导致流动性版本零交易。成交额适配器已增加回归测试并按 `amount × 1000` 修复。
