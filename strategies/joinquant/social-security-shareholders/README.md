# 全国社保基金流通股东策略

## 投资假设

上市公司前十大流通股东中的全国社保基金组合，可能包含机构研究、治理筛选和长期持有信息。策略只使用观察日之前已经公告的股东数据，检验这种公开且滞后的持仓信息是否仍能形成可交易的横截面信号。

这只是待验证假设。社保持仓披露不完整且明显滞后，不能把“国家队持有”直接等同于未来上涨。

## 当前基线

- 数据表：`finance.STK_SHAREHOLDER_FLOATING_TOP10`
- 一季报、半年报、三季报分别在5月、9月、11月首个交易日使用
- 买入日前必须已经公告：`pub_date < buy_date`
- 同一股票的多个社保组合合并持股数量
- 按“社保披露持股数量 × 前一交易日收盘价”排序
- 基线选择前100只并等权持有
- 4月、8月、10月最后一个交易日卖出，次月首个交易日买入
- 排除北交所、上市不足365天、停牌、ST、退市和涨停标的
- 保留手续费、印花税、滑点、跌停卖出失败和A股一手金额约束

`baseline.py` 和每个变体都是可直接复制到聚宽的自包含策略。

## 已知限制

- 前十大流通股东只展示社保基金的部分持仓，无法还原完整组合。
- 公告相对报告期有明显滞后，信号可能已经被市场消化。
- 平台数据可能包含后续修订；必须继续核查历史可见性。
- 当前排序可能主要暴露大盘股和高股价，而非独立的“社保选股能力”。
- 旧回测缺少换手、逐年收益和完整净值导出，暂时不能判断收益来自哪些市场阶段。
- 100只等权需要更高资金，最低佣金和一手约束会影响小资金回测。
