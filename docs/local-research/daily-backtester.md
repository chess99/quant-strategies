# 日线撮合器

`DailyBacktester` 在交易日开盘按目标权重撮合，收盘记录现金、持仓和净值。信号计算由
调用方使用上一交易日数据完成，从执行语义上隔离观察日与成交日。

已实现：

- 卖出优先于买入，卖出失败不会释放虚假现金；
- 股票和 ETF 100 股整手；
- 买卖佣金、最低佣金、股票卖出印花税及 2023-08-28 降税；
- 停牌、ST、涨跌停、缺失开盘价拒单；
- 按日成交量比例限制成交，记录部分成交；
- 现金、持仓成本、订单、成交、每日持仓和净值账本；
- 累计/年化收益、最大回撤、Sharpe、波动率、最长水下期和年度收益。

历史 ST 缺失时默认拒绝买入。探索性研究必须显式设置 `allow_unknown_st=True`，并把
市场状态记为 C 级。撮合器不模拟涨停排队、日内价格路径和冲击成本；这些需要分钟或
逐笔数据，不在当前个人日频平台范围内。
