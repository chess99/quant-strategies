# 全市场公告日财务与历史申万行业

## 财务

`fundamentals_pit` 已从 1,310 只样本扩展到证券主表中的 6,115 只历史 A 股。同步器对每只
证券分别获取东方财富资产负债表、利润表、现金流量表和主要指标，原始 JSON gzip
不可变保存，规范化数据按 `symbol=.../data.parquet` 分区。

全量结果为 340,162 条点时记录、6,064 只成功、51 只明确为空、0 下载失败。每只历史
证券都有 success/empty 状态；当前 5,530 只有效证券中，5,381 只三大核心报表同时存在，
覆盖率 97.31%，超过 95% 验收线。

主要字段当前最新记录覆盖率：

- 收入、净利润、营业利润、ROA、净利率：约 99.10%。
- ROE：98.55%。
- 总资产、总负债、权益、现金、经营现金流：97.31%。
- 毛利率：97.27%；资本开支和自由现金流：96.33%。
- 有息负债：94.50%；单项借款、应付债券和商誉只对部分企业有值，完整报告保留其实际
  缺失率，不将“不适用”静默补零。

2026-07-29 的供应商语义审计又补齐了 16 个单季度字段。东方财富原始利润表和现金流量表
中的中报、三季报是年内累计值；数据层现在按同一财年相邻报告相减，生成单季度收入、成本、
利润、归母利润、扣非利润、经营现金流、资本开支、自由现金流和 EBIT，并用单季度分子及
期初期末资产/权益均值计算 ROA、ROE 与利润率。重建后仍为 340,162 行，但字段增至 55 个，
单季度字段当前覆盖率约 96.7%–99.1%，manifest SHA-256 为
`146b7f59dc0c7e9e1b0ded47e6f5a2c429085cd2439f9d8a7b5df74492286aa6`。

这不是为了迎合聚宽目标而调整因子权重。聚宽官方股票 API 文档明确说明
`get_fundamentals(date=...)` 的利润、现金流和财务指标采用单季度口径；官方 ROE、ROA 与
利润率公式也使用单季度分子。兼容层因此把 `roe`、`roa`、`gross_profit_margin`、
`net_profit_margin`、`net_operate_cash_flow` 映射到对应单季度字段。语义依据见
[聚宽股票 API 文档](https://www.joinquant.com/help/api/getContent?name=Stock)。

统一接口新增 `LocalDataPortal.value_metrics()`，把观察日估值与公告日可见财务按证券合并，
正式提供市值、PE/PB/PS、现金、有息负债、FCF、EBIT、EV 和 EV/EBIT。EV 必须同时具备
市值、现金和有息负债，缺项不补零；EV/EBIT 只对正 EBIT 计算。当前分母是最新可见报告的
累计 EBIT，并非 TTM，接口溯源会明确标注这一限制。该能力解决了原验收规格中“数据存在、
但没有统一可调用 EV/EBIT 口径”的最后一个接口缺口。

每次查询必须传观察日；记录只有在 `notice_date <= observation_date` 时可见。数据商仍
可能把后来修订值回填到旧公告记录，因此质量固定为 B，不宣称严格 vintage A。免费源没有
完整母公司权益历史，ROE 分母暂以总权益代理；这一限制不会被兼容层隐藏。

## 历史申万行业

行业事实源为申万官方 `StockClassifyUse_stock.xls`，SHA-256 为
`63974937b615feec19c6588fac1dec571f714da0364457fbe419b562b5ddadec`。三级变更记录被
规范化为申万一级、二级闭区间，并按证券分区保存。

- 覆盖 5,867/6,115 个历史证券；248 个无官方历史的旧代码有明确清单。
- 当前 5,530 只有效证券全部覆盖。
- 一级 9,174 个区间，二级 11,180 个区间。
- 重叠区间、重复主键和非股票代码均为 0，未来区间使用为 0。

官方表中的 `000852`、`000905`、`000906`、`000985` 与上证指数代码重号。旧版按末六位
连接证券主表，曾把 4 个指数错误写入行业分区；修复后先限定 `asset_type=stock` 再映射，
因此旧报告的 5,871 是“5,867 只股票 + 4 个错误指数”，不是股票覆盖数。

官方文件会随后修订，故历史行业为 B。旧版行业名称字典缺失时保留六位行业代码作为
名称，分组语义仍稳定；绝不再用 2026 当前行业快照回填历史。

## 价值质量端到端验收

`joinquant-value-quality-golden-comparison` 使用全市场历史股票池、公告日财务、观察日
估值、历史申万一级行业和 A/B 级交易状态，在 2019-01-02 至 2023-06-30 完成 54 次
月度调仓：

- 每次都选满 20 只，最少有 995 只合格候选。
- 未来公告和未来行业区间使用均为 0。
- 匹配聚宽 1,000 万元初始资金的正式 v9 本地年化 19.56%，最大回撤 25.68%，
  Sharpe 0.927。
- v1 因验收范围把未持有时期也纳入状态质量检查而失败，按不可变规则保留；v2 修正审计
  口径后通过本地检查；v3 绑定首次重号修复数据；v4 在最终非股票门禁和 manifest 重建后
  重新运行，指标与 v2/v3 一致，作为当前最终本地预检证据。

聚宽 v1 原始 stats 显示平台年化 17.69%、最大回撤 26.21%，但免费日志只覆盖 34/54 个
候选日和 33/54 个持仓日。修正版 v2 用紧凑日志免费取得完整 54/54 个月；平台年化 17.26%、
最大回撤 26.97%，目标、持仓和下单证券重合率分别为 60.46%、60.39% 和 59.21%。

完整日志证明约 40% 的目标差异并非截断假象。使用同一份 v2 目标做本地回放后，持仓和下单
证券重合率达到 99.55% 和 99.42%，先排除了行情和撮合器。随后按官方文档恢复单季度财务
语义，未改策略权重，正式自主选股 v9 与同一聚宽日志的最终 autonomous-v4 对照达到：

- 候选重合 88.15%，持仓重合 88.16%，下单证券重合 86.97%。
- 本地年化 19.56%，聚宽 17.26%，差 +2.31 个百分点。
- 本地最大回撤 25.68%，聚宽 26.97%，差 -1.29 个百分点。
- 54/54 次候选与持仓日志完整，所有未来数据和 A/B 质量门禁通过。

候选、持仓和收益回撤均超过既定严格门槛，迭代 6 已完成。最终对照复用回测
`c29fcd867c0701ef9254567a93475cef` 的既有完整日志，没有新增聚宽运行或额度消耗；对照使用
本地自主选股，不以聚宽目标回放冒充财务层验收。B 级历史修订和 ROE 权益代理仍是正式限制。
