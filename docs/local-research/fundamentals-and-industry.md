# 公告日财务与行业能力

## 财务

`fundamentals_pit` 从东方财富缓存导入 99,642 条有效记录、覆盖 1,310 只股票。查询以
`notice_date` 控制可见性，报告期本身不能使数据提前可见。71 条公告日早于报告期的
异常记录已进入 `quarantine/fundamentals_pit/data.parquet`，不会参与查询。

免费数据可能把后来修订的财务值回填到历史记录，因此质量为 B，而不是严格公告版本
可复现的 A。策略应保存使用的数据 manifest 和点时审计结果。

## 行业

现有 1,310 条东方财富行业分类是 2026-07-26 当前快照，只标记从该观察日起有效，质量
为 C。它不会回填到更早日期。要求最低 B 级历史行业的策略会收到 `DataQualityError`；
即使显式允许 C 级，查询 2019–2025 也返回空集。

## 验收边界

价值质量验收策略使用 B 级公告日财务、B 级日估值和 B 级历史中证800成分，不使用
行业。由于历史 ST 缺失，交易状态仍为 C 级；这轮证明中低频基本面研究可在本地完成，
不代表所有数据已达到实盘或监管级复现标准。
