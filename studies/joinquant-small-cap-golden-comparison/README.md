# 全市场小市值黄金对照

本研究用于验收本地日线撮合器和全市场点时选股，不用于证明小市值因子未来有效。

固定规则：

- 2019-01-02 至 2023-06-30；每月首个交易日开盘调仓；免费源的 A/B 级
  历史涨跌停事实截至 2023-06-30，之后的规则推导行保持 C 级并拒绝正式撮合；
- 观察日是执行日前一交易日；
- 从观察日仍有效的全部历史 A 股开始；因北交所历史涨跌停在免费源中仍是 C 级，
  明确剔除北交所，再剔除上市不足 375 天、ST、停牌和无可用总市值者；
- 按观察日总市值升序选 10 只，等权持有；
- 本地使用 B 级点时估值、A/B 级历史状态和 Qlib B 级日线；
- 本地先完成全市场覆盖、未来数据和撮合账本审计，之后只运行一次必要的聚宽黄金对照。

`joinquant_strategy.py` 是聚宽侧的自包含策略。其 `QR_*` 结构化日志用于导出逐次候选、
订单和实际持仓；`run_local.py` 生成本地不可变预检归档。当前同聚宽资金规模一致的本地证据是
`results/2026-07-28__monthly-small-cap__local-preflight-v5/`，初始资金 1,000 万元；此前
v1-v4 保持不可变。

首次聚宽运行 `54f57cfe180b75d7a8a0b8259d9a99e6` 已按实际源码、完整 922 行日志和原始
stats 归档为 `2026-07-28__monthly-small-cap__joinquant-golden-v1`。平台年化 13.32%、
最大回撤 48.02%；本地年化 30.57%、最大回撤 33.77%。候选重合率 82.04%，但实际持仓
只有 69.79%。日志证明主要平台执行缺陷之一是科创板市价单未设置保护限价，多个 688 目标
被聚宽拒单；因此 v1 是失败证据，不能用作最终黄金基准。

修正版聚宽运行 `fd4f04ed4711b333961fec6244c16e84` 已归档为
`2026-07-28__monthly-small-cap__joinquant-golden-v2`。平台实际源码与准备源码一致，紧凑日志
免费取得 54/54 个候选、订单和持仓月份。保护限价修复后，实际持仓重合率从 69.79% 提升到
77.87%，下单证券重合率从 78.02% 提升到 79.03%；说明修复有效，但仍未达到 80% 门槛。

v2 平台年化 12.06%、最大回撤 48.02%，与本地仍相差 -18.51 和 +14.25 个百分点。平台日志
另有 73 条订单错误，其中 24 条为停牌卖出失败；聚宽因此长期残留若干本地未持有的停牌微盘股。
候选本身仍只有 82.04% 重合，说明剩余差异不只是撮合器，还包括点时市值排序和状态事实口径。
